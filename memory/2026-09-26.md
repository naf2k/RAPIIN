### Temuan kritis: rilis 1.1.0 rusak di Mac Intel → 1.1.1
Uji installer (HOME bersih, py3.10) gagal: `RuntimeError: cargo not found`
saat membangun `cryptography==50.0.1`.

Akar masalah: cryptography 49+ hanya punya wheel macOS **arm64**. Di Mac Intel
uv membangun dari sumber (butuh Rust). cryptography 48.0.1 masih punya wheel
`universal2` untuk macOS + wheel Windows/Linux.

CI **tidak bisa** menangkap ini: runner `macos-latest` = arm64.
Mesin ini "lolos" karena punya Rust (dipasang otomatis puccinialin) dan cache
build uv — bukan jalur bersih.

Perbaikan: pin `cryptography>=42.0,<49`, rilis **1.1.1**, tes agent 43 passed.
Verifikasi publik (py3.10, tanpa Rust): checksum OK, `rapiin` terpasang,
cryptography 48.0.1, tanpa Rust. Commit `335e736`.

Catatan: workflow Release ikut jalan saat push dan menimpa aset rilis; setelah
penimpaan checksum tetap OK.
